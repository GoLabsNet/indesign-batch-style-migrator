# Batch Style Migrator for Adobe InDesign

## Standardize InDesign styles across multiple documents.

Keeping Paragraph, Character, and Object Styles consistent across a large collection of Adobe InDesign documents can quickly become repetitive.

Batch Style Migrator automates style renaming and synchronization across multiple InDesign files, helping production teams standardize document collections without updating every file manually.

## Why this tool exists

InDesign provides several ways to manage and synchronize styles.

However, production projects are not always a single document or an InDesign Book.

Real projects may contain:

* multiple independent InDesign documents
* large document collections
* different versions of templates
* styles that need to be renamed consistently
* matching styles with different properties
* repetitive style updates across many files

When the same operation has to be repeated across a large document collection, manual processing becomes time-consuming and increases the risk of inconsistencies.

Batch Style Migrator automates this repetitive production work.

---

## What it can automate

* Batch processing of multiple InDesign documents
* Paragraph Style renaming
* Character Style renaming
* Object Style renaming
* Style property synchronization from a reference document
* Simulation Mode before processing
* Detailed processing reports
* Optional recursive subfolder scanning
* Updating original documents or generating processed copies
* Automatic handling of matching style conflicts

---

## How the workflow works

```text
Reference document
        ↓
Select files or folder
        ↓
Configure migration
        ↓
Optional Simulation
        ↓
Process document collection
        ↓
Review processing report
```

Instead of repeating the same style operation document by document, the workflow is designed around the document collection.

## Built for production workflows

Batch Style Migrator is designed for workflows such as:

* standardizing styles across publication projects
* updating document collections after template changes
* renaming styles across multiple files
* synchronizing styles from a reference document
* maintaining consistency across large document libraries

For important production work, processed copies can be generated instead of modifying the original documents.

---

## Important Version 1.0 limitation

Version 1.0 processes styles located at the **root level** of the Paragraph Styles, Character Styles, and Object Styles panels.

Styles stored inside **Style Groups** are currently ignored.

Support for Style Groups is planned for a future update.
